INTRODUCTION                                    *greekvars* *greekvars.nvim*

This plugin automatically replaces Greek letter names (like `alpha`, `beta`,
`gamma`) with their corresponding Unicode symbols (α, β, γ) using Vim's
conceal feature.

REQUIREMENTS                                    *greekvars-requirements*

- Neovim 0.5.0 or higher
- Terminal with Unicode support

INSTALLATION                                    *greekvars-installation*

Using lazy.nvim: >lua
    {
      "HadyMash/greekvars.nvim",
      ft = { "lua", "python", "javascript", "typescript", "c", "cpp" },
      config = function()
        require("greekvars").setup()
      end,
    }
<

Using packer.nvim: >lua
    use {
      "HadyMash/greekvars.nvim",
      ft = { "lua", "python", "javascript", "typescript", "c", "cpp" },
      config = function()
        require("greekvars").setup()
      end,
    }
<

SETUP                                           *greekvars-setup*

                                                *greekvars.setup()*
greekvars.setup({opts})
    Configure and initialize the plugin.

    Parameters: ~
        {opts} (table|nil) Optional configuration table with the following keys:
            • {conceallevel} (number) Vim's conceallevel setting (0-3)
              Default: 2
            • {concealcursor} (string) Vim's concealcursor setting
              Default: "nc"
            • {filetypes} (table) List of file types where Greek vars are concealed
              Default: {"lua", "python", "javascript", "typescript", "c", "cpp"}
            • {case_sensitive} (boolean) Whether matching is case sensitive
              Default: true
            • {case_preference} (string) When case_sensitive is false, prefer "lower" or
              "upper" case symbols. Default: "lower"
            • {greek_vars} (table) Custom Greek variable mappings
              Default: {} (uses default mappings)
              Keys are the words to conceal, values are the replacement symbols.
              Can be used to override existing mappings, add new custom symbols,
              or remove defaults (set to false or vim.NIL).

    Example: >lua
        require("greekvars").setup({
          conceallevel = 2,
          concealcursor = "nc",
          filetypes = { "lua", "python", "javascript" },
          case_sensitive = true,
          case_preference = "lower",
          greek_vars = {
            -- Override existing
            alpha = "a",
            beta = "b",
            -- Add custom symbols
            star = "★",
            heart = "♥",
            -- Remove defaults
            gamma = false,
          },
        })
<

COMMANDS                                        *greekvars-commands*

                                                *:GreekVarsToggle*
:GreekVarsToggle
    Toggle Greek variable conceal on/off. When disabled, the conceallevel is
    set to 0. When enabled, it's set back to the configured value.

FUNCTIONS                                       *greekvars-functions*

                                                *greekvars.toggle()*
greekvars.toggle()
    Programmatically toggle Greek variable conceal on/off.

    Example: >lua
        require("greekvars").toggle()
<

CUSTOMIZATION                                   *greekvars-customization*

You can customize the Greek variable mappings using the `greek_vars` option
in the setup function. This allows you to:

- Override existing Greek letter mappings
- Add new custom symbols for any word you want
- Remove default mappings (set them to false or vim.NIL)

Example: >lua
    require("greekvars").setup({
      greek_vars = {
        -- Override existing Greek letters
        alpha = "a",
        beta = "b",
        
        -- Add custom symbols
        star = "★",
        heart = "♥",
        diamond = "♦",
        
        -- Remove defaults
        gamma = false,
        DELTA = vim.NIL,
      },
    })
<

In this example:
- `alpha` will be concealed as "a" instead of "α"
- `beta` will be concealed as "b" instead of "β"
- `gamma` and `DELTA` will not be concealed at all
- All other default Greek letters will continue to use their default symbols
- New words like `star`, `heart`, and `diamond` will be concealed with their
  respective symbols

CASE SENSITIVITY                                *greekvars-case-sensitivity*

By default, the plugin uses case-sensitive matching. You can control this
behavior with the `case_sensitive` and `case_preference` options.

Case Sensitive (Default): >lua
    require("greekvars").setup({
      case_sensitive = true,  -- Default
    })
<

With case-sensitive matching:
- `alpha` matches only `alpha` → α
- `ALPHA` matches only `ALPHA` → Α
- `Alpha` is not concealed

Case Insensitive: >lua
    require("greekvars").setup({
      case_sensitive = false,
      case_preference = "lower",  -- or "upper"
    })
<

With case-insensitive matching:
- `alpha`, `ALPHA`, `Alpha`, `aLpHa` all match and get concealed
- `case_preference = "lower"` uses lowercase symbols (α) for all matches
- `case_preference = "upper"` uses uppercase symbols (Α) for all matches

BEHAVIOR                                        *greekvars-behavior*

The plugin uses Vim's built-in conceal feature to replace text in the buffer
display without modifying the actual file content.

- Only complete words matching Greek letter names are concealed
- The conceal is temporarily disabled during search operations (/ and ?)
  to ensure search highlights work properly
- The conceal respects word boundaries, so `alphabet` will not be concealed
- Concealed Greek characters preserve the syntax highlighting of the original
  text, whether from Vim's traditional syntax, TreeSitter, or LSP semantic
  tokens. This means highlighted function parameters, variables, keywords, etc.
  maintain their colors when concealed

TIPS                                            *greekvars-tips*

- Use |:set conceallevel?| to check the current conceal level
- Use |:set concealcursor?| to check which modes hide concealed text
- Set `conceallevel=0` in your config to disable conceal permanently
- Press |gUU| to toggle case temporarily if you need to see the original text
